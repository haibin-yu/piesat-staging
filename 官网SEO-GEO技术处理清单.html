三、其他公告栏目 · 需补 2 处 + 确认 1 处

3.1 详情页补 BreadcrumbList（待办 #1）

现状：详情页 JSON-LD 只有一条 Article，缺 BreadcrumbList（列表页已有）。在详情页模板补一段，让 AI / 搜索引擎识别栏目层级：

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "BreadcrumbList",
  "itemListElement": [
    { "@type": "ListItem", "position": 1, "name": "首页", "item": "https://www.piesat.cn/" },
    { "@type": "ListItem", "position": 2, "name": "投资者关系", "item": "https://www.piesat.cn/website/cn/pages/investor/investor.html" },
    { "@type": "ListItem", "position": 3, "name": "其它公告", "item": "https://www.piesat.cn/website/cn/pages/investor/investor.html?tab=other" },
    { "@type": "ListItem", "position": 4, "name": "{公告标题}", "item": "{公告 URL}" }
  ]
}
</script>

3.2 确认 JSON-LD 是否模板生成（待办 #2）

seo.head.js 只负责 meta 去重（title / description / keywords 的 data-page-own 标记），不生成 JSON-LD。JSON-LD 内联在页面 HTML，字段规整（带 @id / @graph / isBasedOn / articleSection），大概率是 CMS 模板自动拼的。

请确认一句：「其他公告」详情页模板是否内置了这段 JSON-LD 生成逻辑？是模板自动生成 → 后续每条公告发文人零操作；若是单条手配 → 需评估并入模板。

四、首页层面 · 补全与回防（待办 #3–#6）

4.1 首页 Organization 补 @id + 填 sameAs（#3）

现状：首页 Organization 已挂且完整（含 tickerSymbol / foundingDate / address / logo），但无 @id、sameAs 为空数组。补两处：

"@id": "https://www.piesat.cn/#organization",
"sameAs": [
  "https://www.cninfo.com.cn/new/disclosure/stock?stockCode=688066",
  "http://www.sse.com.cn/assortment/stock/list/info/company/index.shtml?COMPANY_CODE=688066"
]

@id 与列表页 Organization 统一（否则搜索引擎当成两个实体）；sameAs 指向权威披露页，向 AI 证明官网是官方主体、非冒名。

4.2 首页补 WebSite 实体（#4）

现状：首页缺 WebSite 实体（列表页已有）。补一段，与列表页 #website 呼应：

<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "WebSite",
  "name": "航天宏图官网",
  "url": "https://www.piesat.cn"
}
</script>

4.3 首页 title / description 强化品牌全称（#5）

现状：品牌词「航天宏图」排名已从 5.4 跌到 21.3，被新闻媒体挤出首页。品牌词贡献全站 96% 点击，是唯一基本盘。建议：

  • 首页 <title> 用品牌全称「航天宏图信息技术股份有限公司（PIESAT）」开头；
  • description 首句点出「卫星应用 / 遥感信息服务 / PIE 软件」定位，强化品牌实体；
  • 避免堆砌风险类负面词（退市 / 重整等），目标是官方准确表述占位，不是抢负面词流量。

4.4 首页 + 关于页补 viewport（#6）

9 月已定位根因：官网首页 + 关于页缺 <meta name="viewport">，导致移动端搜索点击率仅 0.62%（展现 487、点击 3）。「其他公告」栏目已补，但首页 / 关于页仍未补。在首页与关于页 <head> 加一行：

<meta name="viewport" content="width=device-width, initial-scale=1">
